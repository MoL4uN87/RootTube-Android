# RootTube — пересказ видео на русском

## Источник

В предоставленном снимке HTML страницы YouTube (лекция MIT, videoId
`xAcTmDO6NTI`) обнаружены реальные поля:

```
expandableMetadataRenderer
  .header.expandedTitle.simpleText = "Краткий пересказ от ИИ"
  .expandedContent.videoSummaryContentViewModel.paragraphs[]
    .videoSummaryParagraphViewModel.text.content
```

Данные находятся во встроенном объекте `ytInitialData` исходного HTML
ответа `/watch`. Это неподдерживаемая публичная схема страницы, **не**
официальный стабильный API. Доступность зависит от ролика, языка,
эксперимента YouTube и того, отдаёт ли сервер данные без входа в аккаунт.

## Обработка в RootTube

Кнопка **«Пересказать»** в проигрывателе:

1. Делает один запрос к публичной `https://www.youtube.com/watch?v=<id>`
   без cookies, данных аккаунта или токенов.
2. Из ограниченного по размеру HTML извлекает только текст абзацев
   `videoSummaryContentViewModel`, не описание видео и не предупреждение.
3. Если текст уже русский, показывает его непосредственно.
4. Если текст на другом языке, определяет язык и переводит через **Google
   ML Kit на устройстве**, скачивая языковую модель при необходимости.
5. При отсутствии пересказа, ошибке страницы или недоступности ML Kit
   использует прежнюю подборку ключевых моментов по субтитрам. Если
   невозможно получить русский текст, показывает ошибку, а не английский.
6. Источник помечается явно: «Краткий пересказ от ИИ YouTube» или
   «Ключевые моменты по субтитрам». Сохраняется предупреждение о возможных
   ошибках ИИ.

Перевод готового пересказа производится локально, без Яндекс Браузера,
Алисы и OCR. В резервном режиме существующий Google Translate endpoint
может получать фрагменты субтитров; об этом сообщается при первом нажатии.

## Проверка на телефоне

Открой ролик `xAcTmDO6NTI` → нажми «Пересказать». Если YouTube отдаёт
блок в ответе с телефона, появится готовый пересказ на русском. Если не
отдаёт, приложение перейдёт на резервный механизм по субтитрам.
Первая загрузка модели ML Kit требует доступа к сети.

Unit tests: `YouTubeAiSummaryParserTest` проверяет JSON-структуру,
абзацы, отказ от ложного пересказа, экранирование и повреждённый HTML.
